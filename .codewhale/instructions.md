## Project: ahmedalfahdi.github.io

Personal website built with Astro + Three.js, deployed to GitHub Pages.

## Key architecture

- **Framework**: Astro (static site generator)
- **3D**: Three.js via Model3D.astro and ThreeScene.astro
- **Content**: MDX collections in `src/content/` (career, notes, coding, engineering)
- **Pages**: Astro pages in `src/pages/` with dynamic routes
- **Analytics**: Separate Vercel serverless API at `analytics-api-one.vercel.app` (repo: `AhmedAlfahdi/analytics-api`)
- **Deployment**: GitHub Actions → GitHub Pages (`astro-pages.yml`)

## Analytics API

The analytics backend is a **separate project** deployed on Vercel. It is NOT part of this repo.

- **Live URL**: `https://analytics-api-one.vercel.app/api`
- **Repo**: `github.com/AhmedAlfahdi/analytics-api`
- **Stack**: Vercel Serverless Functions + Vercel KV (Upstash Redis)
- **Endpoints**: `/track`, `/stats`, `/log`, `/badge`
- **Configured in this site**: Via `PUBLIC_ANALYTICS_API` env var or hardcoded fallback in `VisitorTracker.astro`, `BaseLayout.astro`, `statistics.astro`, `visitors-table.astro`
